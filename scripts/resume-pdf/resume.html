A phone agent that answers inbound calls and completes bookings end to end - roughly 126,000 lines of TypeScript across 660 files. Retrieval is one package among many; the rest is Firecrawl-based crawling behind SSRF-guarded URL validation, knowledge compressed into a prompt-ready brief, per-caller memory, and the agent runtime around a live call.
Decisions
Memory carries an explicit trust boundary: anything learned mid-call is written only as a candidate and never reaches the live prompt until a merchant approves it, approved facts cannot be silently downgraded by automatic extraction, and write failures are swallowed so a database error cannot take down the end of a call.
